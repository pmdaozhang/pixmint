Features / 01

不是更多按钮，
是更少切换。

截完就能标注、识别、翻译或钉住。Pixmint 不要求你改变工作流，只把中间那几步变短。

01

截图与标注

框选后直接标注。矩形、箭头、马赛克、文字、序号，选中即可改。

02

钉图

把截图钉在最上层。拖动、缩放、透明度、鼠标穿透，一直留在手边。

03

本地 OCR

PP-OCRv5 本地模型，中英混排、路径、版本号和 IP 都能读；Windows OCR 兜底。

04

翻译

自动判断方向；语言不明确时默认“请选择”，CN→EN / EN→CN 切换即译。

05

GIF / 视频

选区录制、倒计时、系统音或麦克风；预览满意再保存。

06

安静常驻

托盘运行、快捷键可改、设置与诊断齐备；本地优先，不需要账号。
