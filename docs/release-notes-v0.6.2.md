# Pixmint v0.6.2

发布日期：2026-10-30

## 新增

- 托盘右键菜单新增“意见反馈…”。
- 反馈窗口支持直接 `Ctrl+V / ⌘V` 粘贴截图，最多 10 张。
- 单张截图超过 5MB 时自动压缩为 WebP。
- 网络异常时，文字反馈进入本地队列，恢复后在后台自动补发。

## 改进

- 反馈文本提交到生产后台，截图按反馈 ID 逐张上传。
- 相同 `request_id` 重试由后台幂等处理，不会重复生成反馈。
- 应用内自动更新切换到
  `https://pixmint.hugproducthub.top/downloads/`。

## 安装说明

- 支持 Windows 10/11 x64。
- 安装包未代码签名，首次运行可能触发 SmartScreen。
- 0.4.1 及更新版本可在应用内检查更新。
