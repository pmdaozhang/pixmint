## 摘要

**一句话定位**：Pixmint 不是"又一个截图工具"，而是**按一下 F1 就能把屏幕上的任何东西变成文字、图片、视频和待办**的上班族桌面工作台。

**三件事：**

1. **定价**：免费版必须"能当主力用"（截图、标注、钉图、基础 OCR、基础录屏全免费）；付费点是**批量化、专业化、自动化**，不是"能不能用"。终身授权早鸟 ¥168 / 标准 ¥228，覆盖 1.x 大版本。
2. **第二曲线**：云和 AI 能力单独用**点数包 / Pro+ 订阅**计价，不能塞进终身制，否则亏死。
3. **插件化**：核心壳（截图管线、覆盖层、设置、IPC）不做插件；其余功能全部插件化，用 manifest 声明 `plan` 与 `capabilities`，付费门禁和设置开关共用同一套注册表。

竞品最关键的一条教训：**PixPin 把基础 OCR 和 GIF/MP4 录屏都免费了**（¥198 终身只卖进阶项）。这意味着 Pixmint 不能靠"有 OCR""能录屏"收费，只能靠"帮你省下整段时间"收费。

### 1.2 五条定价规律

1. **国内 C 端认"终身"，价格带 ¥50–328。** 低于 ¥50 像玩具，高于 ¥300 需要强理由（uTools 328 靠插件生态，Quicker 980 被用户吐槽）。**¥198 是最强的心理锚点**（PixPin）。
2. **免费版必须能当主力。** PixPin、Snipaste 个人版、PicPick 个人版都不阉割核心能力。凡是把"基础截图/基础 OCR"锁起来的国内产品，口碑都很差。
3. **付费点集中在四类**：① 批量化（批量 OCR、表格、公式）② 专业化（录屏美化、键鼠录制）③ 自动化（工作流、动作库、快捷键编排）④ 云端化（同步、分享链接、团队）。
4. **订阅只在两种情况下成立**：B 端付费（Loom $15/人/月）、或边际成本高（沉浸式翻译 AI token、CleanShot Cloud 存储）。纯本地工具做 C 端订阅，转化率极低。
5. **生态 > 功能。** uTools 能卖 ¥328、Raycast 能卖 $96/年，卖的都是"别人给你做的插件"。这也是 Pixmint 插件化方向的长期价值所在。

### 2.2 你已有 vs 该补

**已有（0.7.0）**：框选截图、标注、钉图、钉图文字选择复制、PaddleOCR + Windows OCR、翻译（OpenAI 兼容 / DeepL）、内置 3 万词词典与单词卡、GIF 录制、视频录制、引导、反馈、自动更新。

**该补（按商业化价值排序）**：

1. **批量 OCR / 表格 / 公式** —— 最容易收费、最容易做出对比演示。
2. **专业录屏**（自动缩放、光标平滑、背景）—— Screen Studio 证明了这个点值 $108/年。
3. **长截图回归** —— 0.6.x 下线了，但这是 PixPin 免费都给的功能，缺了会被直接对比掉。
4. **剪贴板历史 / 历史记录** —— 高频、低开发成本、极强的"工作台"属性。
5. **翻译增强**：双语对照、术语库、划词即译（全局取词）。
6. **工作流类**：截图 → OCR → 翻译 → 复制 一条链，一键完成。
7. **生词本同步 + 复习提醒** —— 把"查单词"变成"每天回来一次"的留存钩子。

## 三、产品定位与分层

### 3.1 定位

> **给上班族的一站式桌面工作台：截图、翻译、钉图、录屏、查词，一个 F1 全搞定。**

不要在官网上和 PixPin/Snipaste 比"截图更快"，那是红海。要比的是 **"一天下来少切换几个软件"**。

## 四、定价方案

### 4.1 建议价格

| 档位             | 价格                | 说明                       |
| -------------- | ----------------- | ------------------------ |
| 免费版            | ¥0                | 永久免费，可个人使用               |
| **Pro 终身（早鸟）** | **¥168**，前 2000 份 | 制造首发动能，低于 PixPin ¥198 锚点 |
| **Pro 终身（标准）** | **¥228**          | 功能补齐后（表格/录屏/长截图）上调       |
| Pro 终身（成熟期）    | ¥298              | macOS 版 + AI 能力上线后       |
| 学生 / 教育        | ¥128              | 需 edu 邮箱验证，5 折左右         |
| Pro+ 订阅        | ¥12/月 或 ¥98/年     | 云同步、AI 翻译额度              |
| AI 点数包         | ¥19 / 1000 点      | 按量计费，不承诺"无限 AI"          |
| 团队版（后置）        | ¥59/人/年           | 共享配置、团队词库                |

**终身授权的边界必须写死**：终身 = 永久使用 + 1.x 大版本内免费更新；2.0 大版本升级享 5 折。这条不写清楚，五年后你会被自己卖过的终身卡住。

### 4.2 为什么这样定

- **贴着 ¥198 锚点往下打**：PixPin 已经很成熟，同样价格你不会赢；低 15% 再加"翻译+词典"的差异化，转化更好。
- **早鸟价制造稀缺**：¥168 限 2000 份，比"打七折"更有效，还能换来第一批种子用户和口碑。
- **不做纯订阅**：国内 C 端本地工具订阅转化率通常低于 3%，而终身买断的即时决策成本低得多。
- **云能力单独收费**：AI/云是唯一会随用户增长而变贵的部分，必须用点数或订阅隔离，否则终身用户越多亏得越多。

### 4.3 粗略收入模型

假设免费用户 10 万、付费转化率 3%：

| 转化率 | 付费用户  | 客单价  | 收入     |
| --- | ----- | ---- | ------ |
| 1%  | 1,000 | ¥200 | ¥20 万  |
| 3%  | 3,000 | ¥200 | ¥60 万  |
| 5%  | 5,000 | ¥200 | ¥100 万 |

再加 Pro+ 订阅：3,000 付费用户中 15% 订阅 ¥98/年 ≈ ¥4.4 万/年（可持续）。

> 结论：**终身制解决现金流，订阅解决长期成本**，两条腿都要有。

### 4.4 转化漏斗

1. **首次体验**：安装后 7 天内不弹付费，只做引导。
2. **触发点**：用户第 1 次批量 OCR、第 1 次尝试表格、第 1 次导出带水印时，弹出"Pro 可解锁"，并给 **7 天全功能试用**（无需付费）。
3. **试用到期**：降级为免费版，保留数据，给早鸟价倒计时。
4. **流失挽回**：30 天未打开 → 发一封"你的早鸟价还剩 3 天"。
5. **口碑**：终身用户生成邀请码，双方各得 3 个月 Pro+ 或 ¥30 抵扣。

## 五、插件架构

### 5.1 分层原则

```
┌─────────────────────────────────────────────┐
│  Core Shell（不是插件，永远在）              │
│  截图管线 / 覆盖层 / 设置 / IPC / 许可 / 更新 │
└─────────────────────────────────────────────┘
              ↕ Plugin Host API
┌──────────────┬──────────────┬───────────────┐
│ 内置插件      │ 内置插件      │ 第三方插件(后期)│
│ ocr-batch    │ record-pro   │ 由市场分发      │
│ dictionary   │ clipboard    │ 签名 + 沙箱     │
└──────────────┴──────────────┴───────────────┘
```

**核心壳不做插件**：截图管线、覆盖层窗口、设置框架、IPC 路由、许可校验必须常驻。否则用户关掉"截图"插件，整个应用就废了。

### 5.2 插件 Manifest

```ts
// src/plugins/<id>/manifest.ts
export interface PluginManifest {
  id: string;                    // 'ocr-batch'
  name: string;                  // '批量 OCR'
  version: string;               // '1.0.0'
  category: 'capture' | 'ocr' | 'translate' | 'record' | 'utility' | 'study';
  description: string;
  icon: string;

  plan: 'free' | 'pro' | 'proplus';        // 付费门禁
  platforms: ('win32' | 'darwin')[];        // 平台可用性
  capabilities: Capability[];               // 运行时能力声明

  entry: {
    main?: string;                            // 主进程入口（可选）
    renderer?: string;                        // 渲染层入口（可选）
  };

  hooks?: PluginHook[];                       // 'after-capture' | 'after-ocr' | 'toolbar' | 'command-palette'
  settingsSchema?: JSONSchema7;               // 自动生成设置 UI
  commands?: CommandManifest[];               // 可绑定快捷键 / 命令面板
}
```

**`plan` 字段就是付费门禁的唯一真相来源**：许可服务返回 `entitlements: ['free','pro']`，插件注册表据此过滤可加载列表，设置页据此显示"需升级"。

### 5.3 运行时结构

```
src/plugins/                 内置插件（编译进包，可懒加载）
  ocr-batch/
    manifest.ts
    main.ts                  主进程侧：IPC handlers、服务
    renderer/                渲染层侧：React 入口
src/main/plugins/
  registry.ts                加载、启停、依赖、版本校验
  host-api.ts                暴露给插件的受控 API
  ipc-broker.ts              plugin:<id>:<channel> 命名空间 + Zod 校验
src/shared/plugins/
  types.ts                   Manifest / Capability / Hook 类型
  entitlements.ts            plan → 可用插件集合
src/renderer/src/plugins/
  PluginHost.tsx             渲染层插件挂载点
  PluginSettings.tsx         schema 驱动的自动设置页
```

### 5.4 设置页开关

设置页读注册表，按 `category` 分组渲染开关：

- 开关状态存 `settings.plugins[id].enabled`
- 关闭插件 → 卸载其 IPC handler、注销钩子、隐藏 UI 入口（不是只隐藏按钮）
- `plan` 高于当前授权的插件显示锁图标 + "升级解锁"，但仍展示功能说明（这是转化入口）
- 每个插件的专属配置由 `settingsSchema` 自动生成，避免为每个插件手写设置页

### 5.5 权限与安全

| 能力                     | 需要授权 | 说明        |
| ---------------------- | ---- | --------- |
| `screen.capture`       | ✅    | 读取屏幕      |
| `clipboard.read/write` | ✅    | 剪贴板       |
| `fs.read/write`        | ✅    | 指定目录      |
| `network`              | ✅    | 外部请求，需列域名 |
| `shell.openExternal`   | ✅    | 打开链接      |

- **内置插件**：编译期信任，但仍走同一套 capability 校验，方便未来下沉到第三方。
- **第三方插件（v2）**：独立目录 + Ed25519 签名 + 在 `utilityProcess` 中运行主进程逻辑，渲染层跑在 sandbox 的 BrowserWindow/iframe 里，只通过 postMessage 暴露白名单 API。**绝不给 Node 权限。**
- 这是 ARCHITECTURE.md 第 7 条"平台特有功能用 feature flag 控制"的自然延伸。

## 六、许可与支付

### 6.1 许可系统（最小可用）

- **授权码**：Ed25519 签名的 license 串，内含 `{ plan, expires, devices, issuedAt }`。
- **离线校验**：公钥内置在客户端，启动时本地验签，**断网可用**（这是国内用户刚需）。
- **在线校验**：每 7–14 天联网续签一次，连续失败给 30 天宽限期（防止改系统时间）。
- **设备绑定**：machine-id 哈希，3 台设备，支持用户自助解绑。
- **服务端**：复用现有腾讯云东京服务器，一个轻量 license API + 订单表即可，不要上 SaaS。

### 6.2 支付渠道

| 渠道                     | 优点                | 缺点         |
| ---------------------- | ----------------- | ---------- |
| 数码荔枝 / 少数派商店           | 国内用户信任度高、能开票、自带流量 | 抽成         |
| 爱发电                    | 个人开发者零门槛          | 不适合软件授权码交付 |
| 官网 + 微信/支付宝（易支付类）      | 利润最高              | 需要企业资质与风控  |
| Paddle / Lemon Squeezy | 海外 + 自动税务         | 国内收款体验一般   |

**建议**：首发走**数码荔枝 + 官网**双渠道，前者带量后者保利润。

### 6.3 防盗版

- 本地功能一定会被 patch，接受这一点：**定价足够低，破解不值得花时间**。
- 真正锁在服务端的能力：AI 翻译、云同步、更新通道（`latest.yml` 可按授权过滤）、团队功能。
- 不要做激进的机器指纹或偷偷上传，差评成本远高于盗版损失。

## 八、风险清单

| 风险            | 影响  | 对策                                        |
| ------------- | --- | ----------------------------------------- |
| 免费版给太多 → 没人付费 | 高   | 付费点必须是"批量/自动化/专业输出"，不是"能不能用"              |
| 免费版给太少 → 没人用  | 高   | 截图/标注/钉图/单次 OCR 永远免费                      |
| 终身制遇上云成本      | 高   | 终身只覆盖本地能力，云能力走点数                          |
| 破解            | 中   | 低价 + 服务端关键能力，不投入反破解军备竞赛                   |
| 插件安全（第三方）     | 中   | v1 只做内置插件；第三方延后并强制沙箱                      |
| 单兵维护成本        | 高   | 插件边界清晰、settingsSchema 自动生成 UI，减少每个功能的重复工作 |
| 跨平台拖慢发版       | 中   | Windows 先跑通商业化，macOS 作为 Pro 涨价理由后置        |
