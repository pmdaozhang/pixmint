# Pixmint Release Notes

## v0.3.10 — 翻译方向下拉常驻（2026-10-26）

- 翻译方向下拉始终显示在原文和译文之间。
- 语言明确时自动选中 `CN→EN` 或 `EN→CN` 并开始翻译。
- 语言不明确时默认显示“请选择”，不会自动猜测，等你自己选择。
- 原文或译文内容超出显示范围时会出现细滚动条，避免误以为内容只有眼前这些。

## v0.3.9 — 翻译方向选择（2026-10-26）

- 截图里中英字符数相等，或只有数字/符号时，不再自动猜测翻译方向。
- 翻译弹框会显示一个紧凑的 `CN→EN / EN→CN` 下拉，默认按界面语言选择方向。
- 中文界面默认 `CN→EN`，英文界面默认 `EN→CN`；切换方向立即重新翻译。
- 下拉无确认按钮，只有两个纯文本选项。

## v0.3.8 — PaddleOCR 本地识别（2026-10-26）

- OCR 默认改用本地 PaddleOCR PP-OCRv5 mobile，不再依赖系统 OCR 的语言包。
- 中英混排、路径、提交号、版本号和 IP 地址识别明显更稳。
- 14px 小字截图也能正确识别版本号和 IP，不再出现 `037`、`127 ℃` 这类结果。
- 首次识别会加载模型，约 0.5 秒；之后单张截图约 1 秒。
- 系统没有可用模型或 PaddleOCR 异常时，会自动回退 Windows OCR。
- 安装包会增大，因为内置了约 21MB 模型和原生 ONNX 运行时。

## 未发布 — 稳定性基础（2026-10-22）

- 设置页新增“诊断”区域，可以查看日志位置、崩溃报告数量和兼容模式状态。
- 设置页可以直接导出一份 JSON 诊断报告，遇到问题时发送给开发者即可。
- 遇到异常退出时，应用会自动保存一份本地诊断报告，方便定位问题。
- 诊断日志改为后台批量写入并自动轮转，长时间使用不会无限占用磁盘。
- 设置和翻译密钥的保存更安全，异常退出时不容易损坏配置文件。

## 未发布 — 首次引导与箭头优化（2026-10-21）

- 产品正式更名为 Pixmint
- 新安装包和可执行文件名称改为 Pixmint
- 原有设置和密钥数据继续沿用，不需要重新配置
- 整体界面改用 Codex 风格的中性灰阶和蓝色主色
- 选中项改为浅灰/深灰底，不再用整块蓝色填充
- 所有窗口、卡片、按钮和弹层统一为 Codex 圆角体系
- 设置、截图、引导、OCR、贴图和录制窗口同步换肤
- 安装后首次启动会显示引导，不再直接弹设置页
- 引导会告诉您默认截图快捷键是 F1
- 划线工具用动画演示两种用法：按住拖拽、单击两次
- 演示动画里鼠标和线头始终重合，两次单击会从起点开始画线
- 第一页框选动画的矩形右下角会一直跟随鼠标
- 引导页两页切换改为柔和淡入淡出
- 箭头样式合并成一个下拉框：带箭头、纯线条、双箭头
- 线条回弯后箭头会沿最后一段实际方向，不再偏向旧轨迹
- 短线和急弯的箭头会按线长缩小，不再比线段还大或乱跳
- 线型下拉框里的所有预览都会显示箭头
- 删除马克笔、虚线和手绘选项，保留实线、细线、点线
- 切回矩形、圆形或箭头工具后，已有标注可以重新选中和移动
- 鼠标移到可移动标注的边框上会显示四向平移光标
- 文字可以直接拖动位置，单击文字仍会进入编辑
- 马赛克工具不会再误拖已经画好的图形
