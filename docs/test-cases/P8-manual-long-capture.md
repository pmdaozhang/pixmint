# 测试用例：手动长截图（P8）

版本：v1 | 上次更新：2026-10-27

> 本文件是 Phase 0 后的测试设计；功能尚未实现，执行结果待 Phase 1–4 填写。

## 正常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-001 | F1 进入覆盖层，框选可滚动区域，选择“手动滚动” | 工具栏出现手动长截图入口，HUD 在选区外显示 |
| TC-002 | 启动后 3 秒倒计时，用户正常向下滚动 5 屏 | 输出高度大于 5 屏，接缝无缺失/重复 |
| TC-003 | 用户以 200px/s 连续滚动 10 屏 | 不需要停顿，屏数和高度持续增加 |
| TC-004 | 用户以 1500px/s 连续滚动 10 屏 | 不需要刻意放慢，仍能接上 |
| TC-005 | 用户使用触控板惯性滚动 | 不要求精确停稳；能接住的帧继续追加 |
| TC-006 | 用户拖动滚动条 | 滚动条不污染匹配，正文连续 |
| TC-007 | 测试页顶部有固定表头 | 表头只出现一次，正文连续 |
| TC-008 | 测试页底部有固定底栏 | 底栏只出现一次或按边界规则处理 |
| TC-009 | 滚动中点击暂停，等 2 秒再继续 | 暂停期间不追加，继续后从当前位置接上 |
| TC-010 | 滚动中点击“回退一屏” | 最后一段被撤销，HUD 高度和屏数同步减少 |
| TC-011 | 滚动中点击完成 | 停止采集，打开预览，保留已接内容 |
| TC-012 | 预览滚轮缩放、拖动滚动 | 长图完整显示，不出现空白或错位 |
| TC-013 | 预览保存 PNG | 文件尺寸与预览一致，重新打开内容完整 |
| TC-014 | 预览复制 | 剪贴板图片尺寸与预览一致 |
| TC-015 | 滚动到底后完成 | 保留最后内容，不重复追加底部 |

## 边界场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-101 | 选区 120×120 | 可以启动；无法滚动时给出明确提示 |
| TC-102 | 选区非常宽、非常窄 | 匹配按实际宽度工作，不崩溃 |
| TC-103 | 选区紧贴屏幕边缘 | 采集和 HUD 不越界，鼠标位置不被破坏 |
| TC-104 | 一次滚动超过选区高度约 80% | 提示“这一帧没接上，请回滚”，不追加错误内容 |
| TC-105 | 小幅反向滚动后再向下滚 | 不重复追加；能从上一张已接受帧继续 |
| TC-106 | 内容只有一屏 | 输出单屏结果并提示内容较短 |
| TC-107 | 达到 30,000px 上限 | 停止并保留已截部分，提示上限 |
| TC-108 | 达到 30M 像素上限 | 停止并保留已截部分，提示上限 |
| TC-109 | Windows 缩放 125% / 150% / 200% | 行号和图像对齐，无重复/缺失 |
| TC-110 | 双显示器，选区在主屏后移到副屏 | 不串屏；窗口移动时暂停并提示 |
| TC-111 | 选区包含输入框光标闪烁 | 稳定帧/匹配策略不产生重复行 |
| TC-112 | 选区包含视频/动画 | 提示动态内容可能影响结果；不因单帧差异崩溃 |

## 异常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-201 | 选区所在窗口完全不可滚动 | 连续多帧无变化后提示“没有检测到滚动” |
| TC-202 | 鼠标在选区外滚动 | 选区画面不变，提示把鼠标放到选区内 |
| TC-203 | 目标窗口被其他窗口遮挡 | 暂停并提示，不把遮挡内容拼进长图 |
| TC-204 | 目标窗口失焦 | 暂停并提示，恢复后继续 |
| TC-205 | 采集帧源超时 | 重试一帧；连续失败停止并保留已接内容 |
| TC-206 | 长图编码失败或内存不足 | 保留已接部分，提示降低高度或分段 |
| TC-207 | 临时目录不可写 | 提示保存失败，不崩溃 |
| TC-208 | 长截图过程中退出应用 | 进程正常退出，临时文件不残留 |
| TC-209 | 用户按 Esc | 取消本次长截图，丢弃结果，覆盖层恢复可用 |
| TC-210 | 自动模式中途丢失重叠 | 不直接预览残缺图；提示继续/改手动/结束保留 |

- 极端快滑、动态内容、懒加载、UAC/受保护窗口必须明确标注 PASS/FAIL/未测。
