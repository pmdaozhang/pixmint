# P13 意见反馈测试用例

| 编号 | 场景 | 输入 / 操作 | 预期 |
|---|---|---|---|
| FB-01 | 托盘入口 | 右键托盘，查看菜单 | “意见反馈…”位于“设置”和“退出”之间 |
| FB-02 | 打开窗口 | 点击“意见反馈…” | 显示反馈窗口，重复点击只聚焦已有窗口 |
| FB-03 | 空内容 | 不输入内容 | “提交反馈”禁用 |
| FB-04 | 文字提交 | 输入内容并提交 | 向反馈接口发送 201 请求，显示成功 |
| FB-05 | 粘贴截图 | 截图后 `Ctrl+V` | 输入框上方立即出现缩略图 |
| FB-06 | 删除截图 | 点击缩略图右上角关闭 | 仅移除对应截图 |
| FB-07 | 10 张上限 | 连续粘贴 11 张 | 保留 10 张并提示上限 |
| FB-08 | 大图压缩 | 粘贴超过 5MB 的图片 | 提交前压缩到 5MB 内 |
| FB-09 | 离线队列 | 断网提交 | 文字写入队列并显示待发送状态 |
| FB-10 | 自动补发 | 恢复网络等待重试 | 队列文字提交成功，服务端只收到一条 |
| FB-11 | 429 / 5xx | 服务端返回对应状态 | 按 2s / 8s / 30s 重试 |
| FB-12 | 400 / 413 | 服务端返回对应状态 | 不重试，界面展示可理解的错误 |
| FB-13 | 附件接口缺失 | 文本成功、附件接口 404 | 文字保持成功，明确提示截图未上传 |
| FB-14 | 隐私说明 | 打开窗口 | 明示内容、版本、系统和截图会发送到反馈后台 |
| FB-15 | 深浅色 | 切换应用主题后打开 | 窗口使用当前主题 |
