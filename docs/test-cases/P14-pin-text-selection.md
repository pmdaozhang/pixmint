# 测试用例：钉图文字选择与复制（对应功能 P14）

版本：v1 | 上次更新：2026-11-03

## 正常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-001 短选区钉图 | 截取约 300×14 的文字区域并钉图 | 图片宽高比与原图一致，窗口不被强制拉高；文字不变形 |
| TC-002 文字识别就绪 | 钉图包含“你好世界” | 后台识别完成，文字层出现，鼠标移到文字上显示文本光标 |
| TC-003 鼠标拖选 | 从文字左侧拖到右侧 | 文字出现选择高亮，选区文本与图片文字一致 |
| TC-004 双击选词 | 双击英文单词或中文词组 | 按浏览器原生规则选中该词 |
| TC-005 全选 | 文字层就绪后按 `Ctrl+A` | 当前钉图全部 OCR 文字被选中 |
| TC-006 复制文字 | 选中文字后按 `Ctrl+C` | 系统剪贴板为选中文字 |
| TC-007 空白区拖动 | 在文字以外区域按住拖动 | 钉图窗口移动，不触发文字选择 |
| TC-008 滚轮缩放 | 文字层就绪后滚轮放大/缩小 | 图片与文字层同步缩放，选择位置不漂移 |
| TC-009 编辑后重识别 | 空格进入标注，添加文字并完成 | 文字层隐藏；新图写回后重新识别 |
| TC-010 图片复制回归 | 点击右上角复制按钮 | 剪贴板为图片，不是文字 |
| TC-011 保存回归 | 点击保存按钮 | 保存的 PNG 内容与钉图一致 |

## 边界场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-012 14px 字体 | 选区高度约 14px，图片文字为 14px 左右 | 钉图保持比例，OCR 尽量识别；不因窗口尺寸造成二次模糊或拉伸 |
| TC-013 高 DPI | 在 150% / 200% 缩放显示器截取短文字 | 使用物理像素裁剪和显示比例映射，图片与文字层对齐 |
| TC-014 超长单行 | 钉图包含一行很长的文字 | 文字层不撑破窗口，行框被裁剪在图片区域内 |
| TC-015 多行文字 | 钉图包含多行中英混排 | 每行文字框独立，全选文本保留行结构 |
| TC-016 极小选区 | 8×8 选区钉图 | 钉图仍保持比例，不崩溃 |
| TC-017 超大选区 | 接近工作区大小的选区钉图 | 按工作区等比缩小，文字层同比映射 |
| TC-018 缩放后编辑 | 先滚轮缩放，再进入标注 | 不因本轮改动产生新的崩溃；旧有编辑行为保持 |

## 异常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-019 OCR 引擎不可用 | 模拟 OCR 抛错 | 钉图正常显示，提示文字识别不可用，图片复制/保存可用 |
| TC-020 OCR 返回空结果 | 钉图为纯色或无可识别文字 | 不渲染文字层，不弹错误，不阻塞其他操作 |
| TC-021 钉图快速关闭 | 钉图后立即关闭 | OCR 结果被丢弃，窗口和 Blob URL 释放 |
| TC-022 连续钉图 | 连续创建多张带文字钉图 | OCR 排队执行，窗口不互相串文字 |
| TC-023 编辑期间 OCR 返回 | 进入编辑后旧 OCR 才完成 | 旧结果不覆盖编辑态，不显示文字层 |
| TC-024 剪贴板写入失败 | 模拟 `clipboard.writeText` 失败 | 给出可见提示，应用不崩溃 |

## 回归范围

改这个功能时，以下功能不能坏：

- 覆盖层框选、移动、缩放、保存、复制、OCR、录制入口。
- 钉图拖动、滚轮缩放、双击鼠标穿透、不透明度、右键菜单。
- 钉图空格进入编辑、标注工具、撤销/重做、完成写回、Esc 退出。
- OCR 结果窗口、翻译窗口、词典与复制文字流程。
- 多显示器 / 高 DPI 下的截图裁剪和钉图位置。

## 资源测试

| 路径 | 操作 | 记录项 | 预算 |
|---|---|---|---|
| 单次钉图完成 | 打开、OCR、选择、复制、关闭 | 私有内存、工作集、进程存活 | 无崩溃；OCR p95 ≤ 1500ms（首次模型加载另记） |
| 连续钉图 | 30 次不同内容钉图并关闭 | 私有内存增长、窗口残留 | 私有内存增长 ≤ 32MB，0 窗口残留 |
| OCR 失败 | 连续触发失败后恢复正常 | 队列可继续、应用可用 | 失败不阻塞后续任务 |
| 编辑重识别 | 标注完成后再 OCR | 旧结果丢弃、新结果生效 | 无文字层错位和串图 |

| TC-002 文字识别就绪 | PASS | `PIN_TEXT_LAYER 你好世界` |
| TC-003 鼠标拖选 | PASS | `PIN_TEXT_MOUSE_SELECTION 你好世界` |
| TC-004 双击选词 | PASS | `PIN_TEXT_DOUBLE_CLICK 世界` |
| TC-005 全选 | PASS | `PIN_TEXT_SELECT_ALL 你好世界` |
| TC-006 复制文字 | PASS | `PIN_TEXT_CLIPBOARD 你好世界` |
| TC-008 滚轮缩放 | PASS | 相对位置 x 0.16636 → 0.16636，y 0.27292 → 0.27290 |
| TC-009 编辑后重识别 | PASS | `PIN_TEXT_AFTER_EDIT 你好世界` |
| TC-010 图片复制回归 | PASS | `pnpm e2e:pin` 剪贴板图片非空 |
| TC-019 OCR 引擎不可用 | PASS | `PIN_TEXT_FAILURE_STATUS 文字识别不可用`，`PIN_TEXT_FAILURE_COPY_IMAGE true` |
| TC-022 连续钉图 | PASS | 30 次 0 崩溃，私有内存下降 55.3MB |
| TC-023 编辑期间旧 OCR 返回 | PASS | 编辑后文字层先清空，再重建为新图结果 |

未实测：150% / 200% DPI 真机、超长单行、超大选区、手工多行换行复制。以上沿用现有高 DPI 回归债务，不把未实测写成通过。
