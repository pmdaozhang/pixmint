# 测试用例：长截图（对应功能 P7）

版本：v1 | 上次更新：2026-10-27

## 正常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-001 | 按 F1 进入覆盖层，框选可滚动区域 | 工具栏出现“长截图”图标按钮 |
| TC-002 | 在 5 屏静态测试页上框选 800×600，启动长截图 | 输出高度大于 3000px，拼接处无缺失或重复 |
| TC-003 | 测试页每行带递增行号，执行长截图 | 行号 1..N 各出现一次，顺序正确 |
| TC-004 | 测试页顶部有固定表头，执行长截图 | 表头只出现一次，正文连续 |
| TC-005 | 测试页包含图片、代码块、深浅色区域 | 拼接处无明显错位、色带或 1px 接缝 |
| TC-006 | 长截图进行中查看进度 HUD | 显示已截屏数、当前高度和状态 |
| TC-007 | 进行中点“暂停”，等待 2 秒再点“继续” | 暂停期间不截图不滚动，继续后从当前位置接上 |
| TC-008 | 进行中点“完成” | 停止滚动，保留已截部分并打开预览 |
| TC-009 | 预览窗口滚轮缩放、拖动滚动 | 长图可完整查看，不出现空白或渲染错位 |
| TC-010 | 预览中保存 PNG | 文件尺寸与预览一致，重新打开内容完整 |
| TC-011 | 预览中复制 | 剪贴板图片尺寸与预览一致 |
| TC-012 | Windows 缩放 125%，重复 TC-002 | 行号和图像对齐，无重复/缺失 |
| TC-013 | Windows 缩放 150%，重复 TC-002 | 行号和图像对齐，无重复/缺失 |
| TC-014 | Windows 缩放 200%，重复 TC-002 | 行号和图像对齐，无重复/缺失 |
| TC-015 | 双显示器，在主屏选区启动后移动到副屏 | 不串屏；窗口移动时停止并提示 |
| TC-016 | 深色主题测试页执行长截图 | 深色背景和文字拼接正确，无亮度断层 |
| TC-017 | 含懒加载图片的页面，滚动后等待加载 | 图片加载完成后才截帧，不出现半张图 |
| TC-018 | 目标窗口是浏览器嵌套滚动容器 | 滚动容器内容连续，页面外层不移动 |
| TC-019 | 选区包含固定底栏 | 底栏只出现一次或按边界规则处理，不重复插入正文 |
| TC-020 | 长截图完成后关闭预览 | 临时文件被清理，应用不残留大文件 |

## 边界场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-101 | 选区 120×120 最小值 | 可以启动；若无法滚动则给出明确提示 |
| TC-102 | 选区非常宽、非常窄 | 匹配仍按实际宽度工作，不崩溃 |
| TC-103 | 选区紧贴屏幕边缘 | 滚动和截图仍在屏幕范围内，鼠标位置可恢复 |
| TC-104 | 滚动步长过大，重叠不足 | 检测置信度低，停止并提示“滚动过快，请重试” |
| TC-105 | 滚动步长过小，连续多帧只前进几像素 | 自动增大滚动量；仍无进展时停止 |
| TC-106 | 目标内容只有一屏 | 输出单屏长图或提示“无需长截图” |
| TC-107 | 达到 30,000px 上限 | 停止并保留已截部分，提示已到上限 |
| TC-108 | 达到 30M 像素上限 | 停止并保留已截部分，提示已到上限 |
| TC-109 | 目标窗口滚动后回弹 | 以稳定帧为准，不把回弹内容重复拼接 |
| TC-110 | 选区覆盖两个滚动容器 | 以指针中心所在容器为准，结果可解释 |
| TC-111 | 选区包含输入框光标闪烁 | 稳定帧重试后消除光标，不产生重复行 |
| TC-112 | 选区包含视频/动画 | 提示动态内容可能影响结果；不因单帧差异停止 |
| TC-113 | 暂停超过 30 秒再继续 | 状态保持，继续后不重复截取已保存内容 |
| TC-114 | 完成时结果高度小于 2 屏 | 仍可预览保存，提示内容较短 |

## 异常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-201 | 目标窗口不可滚动 | 连续 3 次无变化后停止，提示“目标窗口没有滚动” |
| TC-202 | 目标窗口失焦或被其他窗口遮挡 | 停止并提示“目标窗口失去焦点” |
| TC-203 | UAC 提权窗口 / 受保护内容 | 无法截图或滚动时提示，不生成黑图 |
| TC-204 | 滚动 helper 崩溃 | 自动重启一次；仍失败则停止并保留已截部分 |
| TC-205 | `fastCapture` 超时 | 重试一帧；连续失败停止并提示 |
| TC-206 | 长图编码失败或内存不足 | 保留已截部分，提示可降低高度或分段 |
| TC-207 | 临时目录不可写 | 提示保存失败，不崩溃 |
| TC-208 | 应用在长截图过程中退出 | 进程正常退出，临时文件不残留 |
| TC-209 | 用户按 Esc | 取消本次长截图，丢弃结果，覆盖层恢复可用 |
| TC-210 | 选区在截图过程中被拖动/改变 | 锁定首次选区，不跟随变化，结果可解释 |
