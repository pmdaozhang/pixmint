## 自动化计划

- Vitest：OCR 文本清洗、单词/句子分流、OpenAI/DeepL 请求构造、词典查询。
- Electron E2E：OCR 结果窗口加载、编辑原文、复制、未配置翻译提示。
- Windows OCR 集成测试：用固定中文测试图调用系统 OCR，断言文本包含“你好世界”。
- 小图 OCR：`--smoke-ocr-file` 直接识别 135×35 托盘菜单截图，断言完整文本。
- 中英混排：`--smoke-ocr-file` 识别 `tests/fixtures/ocr-mixed.png`，断言提交号、分支、IP、版本号和路径。
- 极小字：`--smoke-ocr-file` 识别 `tests/fixtures/ocr-mixed-small.png`，记录已知限制，不把单次结果当通过依据。
- 翻译方向：`node e2e-ocr-translate.cjs` 用 `ocr-ambiguous.png` 断言默认“请选择”、两项菜单和切换到 `EN→CN`。
