# 测试用例：窗口长截图（对应功能 P8）

## 正常场景

| 用例 | 步骤 | 预期 | 状态 |
|---|---|---|---|
| TC-001 | F1 框选并查看工具栏 | 窗口长截图入口只有图标，无文字 | 通过 |
| TC-002 | 点击长截图图标 | 工具栏旁打开窗口选择器，显示加载状态 | 通过 |
| TC-003 | 等待窗口列表加载 | 显示屏幕和窗口分组、缩略图、窗口标题 | 通过 |
| TC-004 | 选择真实 Edge 窗口 | 冻结截图隐藏，目标窗口上显示默认内容区选区 | 通过 |
| TC-005 | 拖动四角或四边 | 选区变化，另一侧固定，不越出内容区 | 通过 |
| TC-006 | 点击“重新选择” | 重新冻结桌面并打开窗口选择器 | 通过 |
| TC-007 | 再次选择窗口并开始 | HUD 显示准备、滚动、拼接状态 | 通过 |
| TC-008 | 自动滚动至少 2 屏后完成 | 打开长图预览，图片可加载 | 通过，最终 884×1283 |
| TC-009 | 关闭预览 | 预览窗口关闭，临时结果清理 | 通过 |
| TC-010 | 长截图中点击暂停再继续 | HUD 状态切换，采帧恢复 | Demo 通过 |
| TC-011 | 点击“回退一屏” | 已拼接高度和屏数回退一屏 | Demo 通过 |
| TC-012 | Esc 取消选区页或 HUD | 隐藏辅助窗口，不残留旧目标 | 代码路径通过，未单列 E2E |

## 异常场景

| 用例 | 步骤 | 预期 | 状态 |
|---|---|---|---|
| TC-201 | 目标窗口在确认前关闭 | 不显示选区页或给出可读错误 | 代码路径，未单独实测 |
| TC-202 | 目标窗口没有滚动内容 | HUD 显示“目标窗口没有滚动”，可重试或关闭 | Demo 通过，真实应用未单测 |
| TC-203 | 滚动目标 hwnd 与所选窗口不一致 | 停止并提示重新选择窗口 | 代码保护通过 |
| TC-204 | PowerShell 首次 UIA 编译较慢 | 首次请求最多等待 8 秒，超时后提示无响应 | 通过 |
| TC-205 | Sidecar 返回非法协议 | 主进程记录原始响应并提示信息无效 | 已通过 E2E 复现并修复 |
| TC-206 | 自绘、游戏、视频或禁用滚轮应用 | 自动滚动失败时显示错误，不伪造长图 | 未实测 |
