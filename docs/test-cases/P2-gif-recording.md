# P2 GIF 录制 · 测试用例

| 编号 | 场景 | 步骤 | 预期 | 状态 |
|---|---|---|---|---|
| P2-01 | GIF 入口 | 选区后点击 GIF 图标 | 一级工具条隐藏，选区红色待机框，下方出现胶囊控制条，选区不变 | PASS（E2E） |
| P2-02 | 默认参数 | 打开待机控制条 | 固定 15 FPS；固定原始尺寸；固定 3 秒倒计时；最长 60 秒 | PASS（E2E） |
| P2-03 | 倒计时 | 点击开始 | 选区中央 3、2、1，每个 700ms，之后进入录制 | PASS |
| P2-04 | 录制计时 | 录制 5 秒 | 控制条显示计时，红点闪烁 | PASS（E2E） |
| P2-05 | 停止 | 点击停止 | 右下角出现“录制完成”结果卡，保持显示 | PASS（E2E） |
| P2-06 | 录制中控制条 | 观察录制态 | 只有红点、计时、停止；没有取消按钮 | PASS（E2E） |
| P2-07 | 60 秒上限 | 录制到 60 秒 | 自动停止并出现结果卡 | PASS（逻辑） |
| P2-08 | 保存 GIF | 结果卡点击保存 | 保存对话框生成 `.gif`，可打开 | PASS（E2E 落盘） |
| P2-09 | 打开 GIF | 结果卡点击打开 | 系统默认查看器打开 GIF | PASS（实现） |
| P2-10 | 最小选区 | 选区小于 64×64 | 禁止录制并提示 | PASS（逻辑） |
| P2-11 | 控制条与红框排除 | 录制中观察 GIF | 控制条和红框不出现在 GIF 中；红框画在选区外侧 | PASS（E2E 结构验证） |
| P2-12 | DPI 映射 | 150% 缩放下录制 | 录到的区域与选区一致 | TODO（需真实交互桌面手测） |

| P2-15 | GIF 二级菜单 | 选区后点击 GIF | 紧凑胶囊以选区 X 轴居中；开始按钮显示“开始”；取消后恢复工具条 | PASS（E2E） |
| P2-16 | 固定帧率 | 打开待机条 | 不显示帧率设置，固定 15 fps | PASS（E2E） |
| P2-17 | 待机徽章 | 进入 GIF 待机 | 徽章显示“待机 · GIF”，红框不脉冲 | PASS（E2E） |
| P2-18 | 录制中控制条 | 倒计时结束 | 待机条消失，录制条出现红点/计时/停止，并按选区横向居中 | PASS（E2E） |
| P2-19 | 录制中保留边框 | 开始录制后观察选区 | 覆盖层不消失，红框保持并脉冲，徽章显示 `REC · GIF` | PASS（E2E） |
| P2-20 | 准备阶段不锁屏 | 模拟屏幕采集卡住 | 冻结截图立即撤掉，控制窗显示“准备中…取消”；点取消恢复标注界面 | PASS（E2E） |
| P2-21 | 剪切保存与打开文件 | 结果卡选择保存路径后点“打开文件” | 原临时 GIF 被删除，结果卡文件名更新，打开的是新文件 | PASS（E2E） |
| P2-22 | GIF 动图与颜色 | 录制动态彩色画面并查看结果卡/保存文件 | 结果卡直接播放动图；保存文件为多帧 GIF；颜色使用 rgb565 量化 | PASS（E2E + PIL 帧差） |
| P2-23 | 托盘入口移除 | 右键托盘菜单 | 只显示截图/设置/退出，不显示 GIF 录制 | PASS（源码检查 + 启动检查） |

## 自动化计划

- Vitest：尺寸/时长计算、GIF encoder 输入输出。
- Electron E2E：`pnpm e2e:recording` 覆盖待机条、录制中红框、居中控制条、右下角结果卡、保存落盘。
- 真实屏幕捕获：在普通交互桌面手动验证 15 FPS、150% DPI、控制条排除。
