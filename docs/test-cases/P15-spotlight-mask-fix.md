# P15 聚光灯遮罩修复回归测试

- 日期：2026-11-21
- 背景：聚光灯遮罩原实现「主画布盖全屏黑纱 → destination-out 挖洞」会把亮区内的标注一起擦掉，靠半透明重描补救，导致亮区内箭头/文字/序号蒙白纱、文字换位输入丢失。现已改为「遮罩画布上铺黑纱并挖洞，整张叠加」，重描层删除；文字草稿改为 pointerdown 入口直接提交。
- 验证方式：**全部手工真实操作**（按 F1 实测），不使用任何模拟脚本。
- 环境要求：Windows 11，开发版（pnpm dev 或 electron.exe .），显示器缩放 100% 和 150% 各过一遍标记 ⚠️ 的项。

## 通过标准

- [ ] P0（全部通过才算修复成立）
- [ ] P1（主要用户路径，至少 90% 通过）
- [ ] P2（边界情况，发现问题记录但不算阻断）

任何一步失败：记下「操作 → 看到了什么 → 期望什么」，截图保留。

## P0 修复直接验证（不做完不能停）

### P0-1 亮区内标注不被压暗
1. F1 框选一块白底区域（比如空白网页）
2. 矩形工具 → 打开聚光灯 → 画一个大矩形（亮区）
3. 在亮区**内**画一个红色箭头；在亮区**外**画一个同样颜色的箭头
- [ ] 亮区内箭头颜色饱满，与亮区外箭头颜色**完全一致**（用截图并排对比）
- [ ] 无白纱/白雾感

### P0-2 文字连续输入（本次修复点）
1. 聚光灯开启，画好亮区
2. 文字工具，亮区内点一下，输入「测试一」，**不要按任何确认**，直接在亮区另一个位置点一下，输入「测试二」
3. 再到亮区**外**点一下，输入「测试三」
- [ ] 三段文字全部保留，位置正确
- [ ] 不出现：输入第二段时第一段消失

### P0-3 序号与箭头在亮区内可用
1. 聚光灯开启，亮区内：序号工具连点两下（不同位置）
2. 箭头工具拖两条线（一条在亮区内、一条跨过亮区边界）
- [ ] 序号正常显示，一次点击一个编号
- [ ] 箭头两条都画出来，颜色一致

### P0-4 导出一致性
1. 完成 P0-1~P0-3 后，分别点「复制」和「保存」
- [ ] 复制到画图/微信粘贴的图：亮区内标注依旧饱满，和屏幕上看到的一致
- [ ] 保存的 PNG 文件同上
- [ ] 钉图打开的小窗里同上

## P1 主要用户路径

### P1-1 聚光灯开关与切换
- [ ] 画完聚光灯矩形后，关掉聚光灯开关，再画普通矩形 → 显示为普通矩形边框，不产生遮罩
- [ ] 同一选区内：先画聚光灯矩形 A，再画聚光灯椭圆 B，两者部分重叠 → 重叠区**不会**更暗（历史 bug：重叠变暗）
- [ ] 聚光灯矩形 + 聚光灯椭圆各一个，不重叠 → 两个亮区都正常

### P1-2 编辑已有标注 ⚠️
- [ ] 移动工具（或形状工具）拖动亮区内的聚光灯矩形 → 遮罩跟着移动，亮区里已有的标注不跟着跑（标注不绑定聚光灯是预期行为）
- [ ] 拖动亮区内的箭头 → 箭头可拖动，拖出亮区后变暗（这是聚光灯语义，正确）
- [ ] 双击亮区内的文字 → 重新进入编辑，改完确认后保留
- [ ] 撤销（Ctrl+Z）逐个回退聚光灯矩形和标注 → 每步画面正确；重做同样

### P1-3 文字编辑进阶
- [ ] 亮区内输入文字过程中按 Esc → 草稿丢弃，不留下半个字
- [ ] 文字输入一半时点工具栏的「钉图/复制」按钮 → 上面的文字**保留**在结果里（不确认直接出图，草稿也要落盘）
- [ ] 亮区**边缘**输入文字（一半在亮区一半在暗区）→ 不报错，文字正常显示，亮区外那半略暗属正常
- [ ] 修改文字后（双击编辑）再换位置新建 → 旧的还在

### P1-4 其他工具与聚光灯共存
- [ ] 亮区内外各画一笔马赛克（笔刷和矩形模式都试）→ 马赛克显示正常
- [ ] 聚光灯矩形上再画一个**普通**矩形（不开聚光灯）压在上面 → 普通矩形完整显示
- [ ] 切换线型（实线/虚线/手绘）再画箭头 → 正常
- [ ] 改颜色再画 → 新颜色正常，旧标注颜色不变

### P1-5 选区操作 ⚠️
- [ ] 画完标注+聚光灯后，拖动选区边框改大小 → 标注内容随之平移，不丢失不变形
- [ ] 选区拖到很小再放大 → 遮罩与标注位置关系保持

## P2 边界与异常

### P2-1 极端形状
- [ ] 聚光灯矩形画得**极小**（几乎一个点）→ 不崩溃，遮罩几乎全暗，无异常闪烁
- [ ] 聚光灯矩形画得**超出选区**（从选区内往边框外拖）→ 无异常
- [ ] 反向拖拽（从右下往左上画矩形）→ 亮区位置正确
- [ ] 画好聚光灯矩形后把它拖到选区**外**一部分 → 遮罩裁剪正常

### P2-2 文字边界
- [ ] 输入超长文字顶到选区边缘 → 触发「超出截图区域」提示而不是错位
- [ ] 输入多行（回车换行，注意是 Ctrl+Enter 提交、Enter 是否换行按现行设计）→ 行为一致
- [ ] 亮区内文字 → 拖动它到暗区 → 变暗；再拖回亮区 → 恢复饱满

### P2-3 状态切换
- [ ] 画了一半聚光灯矩形（还没松手）时按 Esc → 取消，无残留遮罩
- [ ] 输入文字未确认时按 Esc → 草稿丢弃；紧接画箭头 → 正常（状态机没被搞乱）
- [ ] 快速连续操作：画箭头→马上点序号→马上输入文字 → 无状态错乱

### P2-4 主题与缩放 ⚠️
- [ ] 系统深色模式下重复 P0-1 → 结果一致
- [ ] 显示器缩放 150%（高 DPI）下重复 P0-1、P0-2 → 导出图分辨率正确，无错位

### P2-5 性能体感
- [ ] 开聚光灯后拖动亮区里的箭头 → 跟手，无肉眼可见卡顿
- [ ] 5 个聚光灯 + 20 条标注的画布上继续操作 → 无明显变慢
