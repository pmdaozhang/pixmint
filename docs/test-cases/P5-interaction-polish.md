# 测试用例：交互完善（对应功能 P5）

版本：v3 | 上次更新：2026-10-25

## 正常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-001 | 截图后点“识别”，OCR 超过 150ms | 出现“识别中...”toast，结果窗口打开后消失 |
| TC-002 | 截图后点“翻译” | 只显示“识别中...”，不显示“翻译中...” |
| TC-003 | GIF 点开始录制 | 准备/倒计时/录制期间红框和遮罩保持，控制条计时递增 |
| TC-004 | 视频点开始录制 | 准备阶段不出现蒙版消失/重现；录制中不反复闪烁 |
| TC-005 | 钉图后按空格 | 窗口向下扩展，图片下方出现工具栏 |
| TC-006 | 编辑模式点矩形工具 | 二级菜单展开，线宽/线型/颜色可用 |
| TC-007 | 编辑模式画一个矩形 | 左箭头可用，右箭头初始不可用 |
| TC-008 | 点对勾 | 编辑后的图写回钉图，退出编辑，窗口恢复原 bounds |
| TC-009 | 编辑模式按 Esc | 退出编辑，不写回图片 |
| TC-010 | 真实截图录 2 秒 GIF，逐帧比较 | 帧间平均差异 ≤ 1，无闪帧 |
| TC-011 | 真实截图录 2 秒视频，逐帧比较 | 帧间平均差异 ≤ 1，最大差异 ≤ 2 |
| TC-012 | 录制中强制崩溃覆盖层渲染进程 | 覆盖层隐藏/销毁，鼠标穿透恢复，控制条关闭，桌面可操作 |
| TC-013 | 视频开启系统音录制 5 秒 | 不崩溃；预览 `hasAudio=true`；文件包含音频流 |
| TC-014 | 钉图编辑点文字工具并输入“钉图文字” | 出现文字输入框，回车后文字绘制到画布，撤销可用 |
| TC-015 | 截图框选完成 | 工具栏默认选中“移动选区”，矩形工具未选中；选区内鼠标为抓取手型（`grab`），选区外不显示十字 |
| TC-016 | `move` 状态下按住选区中央拖动 40×30 | 按下时切换为握紧手型（`grabbing`），移动全程保持 `grabbing`，不回落为箭头；选区同步移动、宽高不变；松开恢复 `grab` |
| TC-017 | 绘制工具和“移动选区”来回切换 | 绘制工具仍可标注，切回移动后光标恢复 `grab`，可继续拖动选区 |
| TC-018 | 钉图后切换到记事本/设置窗口 | 钉图仍保持在其他窗口上方 |
| TC-019 | 钉图窗口按住图片拖动 80×50 | 按下和移动全程为 `grabbing`，不回落为张开手；窗口跟随移动，松开恢复 `grab` |

## 边界场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-101 | OCR 在 150ms 内完成 | 不显示 toast，不闪窗 |
| TC-102 | 钉图靠近屏幕边缘进入编辑 | 窗口扩展后仍在工作区内 |
| TC-103 | 钉图编辑中打开二级菜单 | 工具栏不被裁切 |
| TC-104 | 将选区拖动到屏幕四边 | 选区停在边界内，尺寸不变，光标保持 `grabbing` |

## 异常场景

| 用例 | 步骤 | 预期 |
|---|---|---|
| TC-201 | 录制准备阶段取消 | 回到工具条，冻结画面恢复，红框消失 |
| TC-202 | 钉图 commitEdit 失败 | 提示保存失败，不退出编辑 |
| TC-203 | OCR 失败 | toast 消失，显示 OCR 错误 |

## 回归范围

- 截图框选、标注、复制、保存、钉图
- 默认抓取手型（`grab` / `grabbing`）、选区拖动全程不回落为箭头、钉图拖动全程不回落为张开手、移动/绘制工具切换
- 钉图拖动、缩放、透明度、鼠标穿透、复制、保存
- 钉图切换应用后的置顶层级
- GIF / 视频录制、暂停、停止、预览
