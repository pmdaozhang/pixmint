# Pixmint v0.6.0（Windows）

本次新增“手动滚动长截图”，用于目标应用自动滚动不可靠的场景。

## 新增

- 自动长截图失败后，HUD 增加“改手动滚动”按钮，不需要重新框选。
- 手动模式由用户自己滚动目标窗口，应用只负责定时采帧、稳定帧检测、重叠匹配和拼接。
- HUD 显示“请慢慢向下滚动，停一下再继续”、已截屏数和当前高度。
- 滚动太快或找不到重叠时提示“滚动太快，请慢一点或回滚到重叠位置”，不会直接终止。
- 支持暂停、继续、完成、取消；完成后的预览、保存、复制和临时文件清理与自动模式一致。

## 验证

- 手动模式 smoke：fixture 按 300px/700ms 自动滚动，输出 700×2934、9 屏。
- 长截图 E2E：自动模式、手动入口、取消清理、不可滚动窗口全部通过。
- 普通/滚动条/UIA 大滚轮 smoke 回归通过。
- `pnpm typecheck`、`pnpm test`（145 项）、`pnpm build` 通过。

## 已知限制

- 手动模式需要用户参与滚动；滚动太快时会提示重试。
- 动态内容、固定表头、滚动条仍可能影响拼接质量。
- VS Code、UAC/受保护窗口、网络懒加载图片未验证。
- 125% / 150% / 200% DPI 和多显示器按用户要求不测。
- 安装包未代码签名，首次安装可能触发 SmartScreen。

## 升级

- 0.5.2 → 0.6.0 已实测：差分下载命中 54 个块，重启安装后版本变为 0.6.0。
- 0.4.1 也可直接更新到 0.6.0。
- 0.3.10 老用户需先手动安装一次 0.4.0。
