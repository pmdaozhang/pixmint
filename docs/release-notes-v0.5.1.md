# Pixmint v0.5.1（Windows）

这是 0.5.0 的长截图修复补丁。

## 修复

- 修复长截图选区包含滚动条时，滚动条位置变化会污染整行匹配、导致“无法找到重叠区域”的问题。匹配时裁掉左右 24px，最终拼接仍保留完整选区。
- 首次滚动幅度过大时，不再继续向下滚；会回滚到起点并尝试更小步长，仍失败时提示“请框选更高的区域或关闭单页滚动后重试”。
- 保留 0.5.0 的 1px 接缝修复、HUD、预览、保存/复制和取消清理。

## 验证

- 带移动滚动条的测试页：700×3396，完整拼接。
- 普通长截图 smoke：700×3396。
- 长截图专用 E2E：入口、HUD、暂停/继续/完成/取消、预览、复制、保存路径、不可滚动窗口全部通过。
- `pnpm typecheck`、`pnpm test`、`pnpm build` 通过。

## 已知限制

- 如果目标应用一次滚动就超过整个选区高度，仍然没有可拼接重叠；请框选更高的区域或关闭单页滚动。
- VS Code 长文件因本机现有会话阻塞未验证；UAC/受保护窗口、网络懒加载图片未验证。
- 125% / 150% / 200% DPI 和多显示器按用户要求本轮不测。
- 安装包未代码签名，首次安装可能触发 SmartScreen。

## 升级

- 0.5.0 及更新版本可在应用内检查更新到 0.5.1。
- 0.4.1 也可以直接更新到 0.5.1。
- 0.3.10 老用户需先手动安装一次 0.4.0。
