# P12 首次引导功能导览

状态：已实现并通过 E2E（2026-10-28）

## 背景

0.6.1 的首次引导只有「快捷键」和「划线工具」两页，无法说明长截图、GIF、视频、OCR 这些主功能。本次把引导扩展为 6 页，每页配一段循环动画。

## 页面与文案

| 页 | 标题 | 小字 | 标签 |
|---|---|---|---|
| 01 长截图 | 可以截长图啦！ | 从当前位置开始，自动向下滚动、匹配重叠并拼接。适合聊天记录、网页和长文档。 | 截长图 / 自动滚动 / 自动拼接 |
| 02 GIF | 支持录制 GIF 动画 | 划定区域后点 GIF 按钮，自动录制框选区域，最长 60 秒。 | GIF 录制 / 最长 60 秒 |
| 03 视频 | 视频也能录制 | 按框选区域录制视频，支持麦克风和系统声音，高清 1080P。 | 视频录制 / 高清 1080P |
| 04 OCR | OCR、翻译页都有 | 框选内容，OCR 识别、翻译任你选，一键复制更方便。 | OCR 识别 / 中英互译 |
| 05 快捷键 | 按一下 F1，截下眼前的画面。 | 保留 0.6.1 原有内容 | 默认 F1 / 框选截图 / 可修改快捷键 |
| 06 划线 | 拖一下，或者点两下。 | 保留 0.6.1 原有内容 | 按住拖拽 / 单击两次 / 线条风格 |

## 动效

所有动画由 `useSceneLoop` 统一用 `performance.now()` 推进，离开当前页即停表；`prefers-reduced-motion` 下只渲染一个静态中间态。

- 01：文档上下滚动，选区扫描线扫过，右上角「已拼接 N 屏」循环计数。
- 02：虚线选区绘制，光标尖端与选区右下角完全重合；绘制完成后出现 `REC · GIF 00:0X.X` 计时条，帧格逐个点亮，开关切到开启态。
- 03：本地 8.2 秒无缝循环录屏作为画面；光标绘制选区后边框转红，显示闪烁红点与 `REC 00:0X` 计时。
- 04：先显示中文原文，光标框选后下方浮出「识别原文 / 翻译结果」卡片，整体在视觉面板中水平、垂直居中。

## 引导版本

设置新增 `onboardingVersion`，当前版本号为 `2`。

- 新装用户：`0` → 展示一次。
- 0.6.1 及更早用户：只有 `onboardingCompleted: true`，归一化时视为版本 `1` → 升级后展示一次。
- 展示完成写入 `onboardingVersion: 2`，之后不再出现。
