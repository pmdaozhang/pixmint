# P3 视频录制 · 需求与验收

> 项目：Pixmint  
> 版本：0.3.3  
> 日期：2026-10-20  
> 状态：已实现

## 1. 目标

在截图页面上直接录制选区视频：框选 → 设置参数 → 倒计时 → 录制/暂停 → 停止 → 预览 → 保存。录制过程不把覆盖层、控制条录进画面。

## 2. 功能范围

### 2.1 入口

- 截图工具条增加视频录制图标。
- 托盘菜单增加“视频录制 F4”。
- 全局快捷键 `F4` 进入截图并自动打开视频录制设置。
- 选区宽高均 ≥ 64px 才允许录制。

### 2.2 录制设置

- 点击工具条视频图标后，一级工具条整体隐藏。
- 选区变为红色待机框，左上角显示“待机 · 视频”徽章。
- 选区下方出现紧凑胶囊控制条：开始按钮、计时、麦克风、系统音、取消。
- 开始按钮显示红色圆点和“开始”文字。
- 输出尺寸固定为原始尺寸（长边上限 1920）。
- 倒计时固定为 3-2-1。
- 麦克风：默认开启。
- 系统音：默认关闭；平台支持时可用。
- 视频帧率固定 30 FPS。

### 2.3 录制控制

- 倒计时在选区内显示大号数字，待机控制条隐藏。
- 录制时显示独立控制条：红点、计时、暂停/继续、停止；不提供取消按钮。
- 控制条置顶、无边框、内容保护，按选区 X 轴横向居中，且位于选区外。
- 录制期间覆盖层保持可见，红框和 `REC` 徽章留在屏幕上；红框画在选区外侧，裁切只取选区内部。
- 全屏覆盖层不启用内容保护，避免 Windows 捕获整块变黑。
- 点击开始后覆盖层立即鼠标穿透并撤掉冻结截图；准备阶段只保留红框和“准备中”徽章，避免挡住桌面和权限弹窗。
- 准备阶段由独立控制窗提供“准备中…取消”；渲染层 9 秒、主进程 10 秒初始化超时后自动退出。
- 录制会话期间注册全局 `Esc`，覆盖层或渲染进程卡住时可直接取消。
- 最长 10 分钟，到点自动停止并进入预览。
- 暂停期间计时停止，录制流暂停。

### 2.4 编码与结果卡

- 优先使用 `video/mp4;codecs=avc3,mp4a`，避免 `avc1` 在 canvas 采集下提前结束视频轨；再回退 `avc1`。
- 当前 Electron/系统不支持 MP4 时，自动回退 WebM（VP9/VP8 + Opus）。
- 结果卡、文件名和保存对话框使用实际扩展名，不伪装格式。
- 结果卡固定在屏幕右下角，宽 300px，显示“录制完成”、文件名、尺寸、时长、格式、文件大小。
- 保存：系统保存对话框，把临时 `.mp4` 或 `.webm` 剪切到目标位置，默认临时文件不保留。
- 打开：用系统默认播放器打开结果文件。
- 结果卡保持显示，直到用户关闭。

## 3. 非目标

- 视频裁剪、拼接、变速、字幕
- 鼠标高亮、键盘按键提示
- 摄像头画中画
- 多选区同时录制
- 内置 FFmpeg 转码

## 4. 交互流程

```text
选区 → 视频待机胶囊 → 3-2-1 → 录制中 ⇄ 暂停 → 停止 → 右下角结果卡 → 打开/保存/关闭
```

异常路径：

- 屏幕捕获权限失败：提示检查屏幕录制权限，回到待机控制条。
- 麦克风/系统音不可用：继续录制无声视频，并在结果卡中标注。
- 编码格式不支持：提示当前系统不支持视频录制编码。

## 5. 技术方案

- 捕获：主进程 `desktopCapturer` 获取 screen source，渲染层 `getUserMedia`。
- 裁切：Canvas 按选区裁切，按 `scaleFactor` 映射物理像素。
- 画面：canvas 挂到 DOM，使用 `captureStream(0)`，每帧 `requestFrame()` 手动驱动，避免静止画面下视频轨停止。
- 声音：麦克风与系统音分别 `getUserMedia`，合并为一条 `MediaStream`。
- 编码：`MediaRecorder`，按候选 MIME 依次探测；1 秒分块通过 IPC 写入主进程临时文件，写盘失败会取消录制并提示。
- 窗口：录制控制条和结果卡独立创建；覆盖层在录制期间保持可见但鼠标穿透。
- 边框：覆盖层内使用 `outline` 画在选区外侧，裁剪区域从选区边界开始，红框不进入成片。
- 结果卡：`snapglass-media://` 自定义协议读取临时文件。
- 稳定性：选区外遮罩使用四块纯色矩形，禁止全屏超大 `box-shadow`；覆盖层每 500ms 发心跳，主进程 2 秒无心跳后启用全局 `Esc`，5 秒无心跳或收到 `unresponsive` 时强制鼠标穿透并隐藏。
- 编码稳定性：Windows 默认关闭硬件视频编码，使用软件编码；检测到上次会话未正常结束后，下次启动自动关闭硬件加速。
- 全屏录制：倒计时阶段保留控制条和取消按钮；录制阶段覆盖层降为 `floating`，控制条保持 `screen-saver`，避免控制条被全屏覆盖层遮挡。
- 启动兜底：视频写入初始化 5 秒超时；倒计时后 12 秒未进入 `recording` 自动中止并隐藏覆盖层；录制会话期间系统级 `Esc` 可直接取消。

## 6. 验收标准

- 选区可进入视频待机控制条，开始按钮显示红色圆点和“开始”文字。
- 倒计时结束后开始录制，计时准确，可暂停/继续。
- 录制控制条按选区横向居中，不出现在视频画面中。
- 当前环境支持 MP4 时生成可播放 `.mp4`；否则生成 `.webm` 并明确标注。
- 保存文件可被系统播放器打开。
- 结果卡保持显示，直到用户关闭。
- 错误路径能回到待机控制条并提示原因。

## 7. 已知限制

- MP4 支持取决于 Electron/Chromium 与系统编码器；不支持时回退 WebM。
- 系统音在 Windows 为尽力而为，macOS 需要系统权限与平台能力。
- 视频固定 30 FPS，暂不提供帧率选择。
- 10 分钟上限用于控制临时文件体积与内存压力。
- 录制期间用户切换窗口会被正常录下。
- Windows 软件编码会增加 CPU 占用；这是为了避免部分显卡驱动在 1080p 硬件编码时卡死桌面。
- 进入兼容模式后会持续关闭硬件加速，直到手动删除用户数据目录下的 `recording-safe-mode.json`。
