# P13 意见反馈

## 目标

在 Pixmint 托盘菜单提供“意见反馈…”，打开独立反馈窗口。用户可以描述问题、
直接按 `Ctrl+V` 粘贴截图并在同一窗口提交，不需要先保存图片或选择文件。

## 用户路径

1. 右键托盘图标，点击“意见反馈…”。
2. 输入反馈内容。
3. 截图后按 `Ctrl+C`，回到反馈窗口按 `Ctrl+V`。
4. 截图以缩略图显示在输入框上方，可删除单张或继续粘贴。
5. 点击“提交反馈”，看到提交结果。

## 约束

- 内容必填，最长 1000 字。
- 最多 10 张截图。
- 单张截图提交前不超过 5MB；超过时在渲染层压缩为 WebP。
- 截图只在内存中流转，不写入本地文件。
- 网络不可用时，文字反馈写入 `userData/feedback-queue.json`，后续自动补发。
- 离线队列不持久化截图；应用退出前未发送的截图不会跨重启保留。
- 网络请求只在主进程执行，渲染层继续启用 sandbox 和 contextIsolation。

## 提交契约

- 文本：`POST https://data.hugproducthub.top/api/v1/feedback`
- 附件：`POST /api/v1/feedback/<id>/attachments`
- `tool=pixmint`
- `type=other`
- `request_id` 使用 `crypto.randomUUID()`，重试时复用。
- 429、5xx 和网络错误按 2s → 8s → 30s 重试；400/413 不重试。
- 详细契约见 `docs/integrations/feedback-backend-contract.md`。

## 验收

- 生产后台 2026-10-30 已上线文本和附件接口；`e2e:feedback:live` 联调通过。
- 托盘菜单出现反馈入口。
- 真实系统剪贴板粘贴截图后立即出现缩略图。
- 10 张上限、单张删除、超限提示正常。
- 离线时文字进入队列，恢复网络后自动补发。
- 文本提交成功后附件按后台附件接口上传，单张 5MB、最多 10 张。
- 附件上传失败时，文字反馈保持成功，界面明确提示截图未上传。
