# P2 GIF 录制 · 需求与验收

> 项目：Pixmint  
> 版本：0.3.3  
> 日期：2026-10-20  
> 状态：已实现（GIF 录制、编码、预览、保存、首帧复制）

## 1. 目标

在截图选区上直接录制 GIF：框选区域 → 设置参数 → 倒计时 → 录制 → 预览 → 保存/复制。录制过程不把覆盖层和控制条录进 GIF。

## 2. 功能范围

### 2.1 入口

- 截图标注工具条增加 `GIF` 入口。
- 托盘菜单增加“GIF 录制”（截图后进入同一流程）。
- 只有选区宽高均 ≥ 64px 时才允许录制。

### 2.2 录制设置

- 点击工具条 GIF 图标后，一级工具条整体隐藏。
- 选区变为红色待机框，左上角显示“待机 · GIF”徽章。
- 选区下方出现一条紧凑胶囊控制条：开始按钮、计时、取消。
- 点击取消恢复一级工具条，不改变选区。
- 采集节奏固定 15 FPS，不提供帧率设置；大选区受 GIF 编码性能限制时按真实时间补帧，避免加速。
- 输出尺寸固定为原始尺寸（长边上限 1920），不提供尺寸选项。
- 倒计时固定为 Demo 的 3-2-1。
- 最长时长：60 秒，到点自动停止并进入预览。

### 2.3 录制控制

- 倒计时在选区内显示大号数字，待机控制条隐藏。
- 录制时显示独立的小控制条：红点、计时、停止；不提供取消按钮。
- 控制条置顶、无边框、`setContentProtection(true)`，不出现在 GIF 中。
- 录制期间覆盖层保持可见，红框和 `REC` 徽章留屏幕上；红框画在选区外侧，裁切只取选区内部，因此不会进入 GIF。
- 全屏覆盖层不启用内容保护，避免 Windows 捕获整块变黑。
- 点击开始后覆盖层立即鼠标穿透并撤掉冻结截图；准备阶段只保留红框和“准备中”徽章，避免挡住桌面和权限弹窗。
- 准备阶段由独立控制窗提供“准备中…取消”；渲染层 9 秒、主进程 10 秒初始化超时后自动退出。
- 录制会话期间注册全局 `Esc`，覆盖层或渲染进程卡住时可直接取消。
- 停止后显示右下角结果卡；结果卡保持显示，直到用户关闭。

### 2.4 结果卡与输出

- 结果卡固定在屏幕右下角，宽 300px，显示“录制完成”、可直接播放的 GIF 动图预览（失焦后继续播放）、文件名、尺寸、时长、文件大小。
- 保存：系统保存对话框，把临时 `.gif` 剪切到目标位置，默认临时文件不保留。
- 打开：用系统默认查看器打开结果文件。
- 关闭：结束本次截图/录制流程。

## 3. 非目标

- 声音、麦克风和系统音
- MP4 / WebM 视频输出
- GIF 裁剪、变速、逐帧编辑
- 鼠标高亮、键盘按键提示
- 多选区同时录制

## 4. 交互流程

```text
选区 → GIF 待机胶囊 → 3-2-1 → 录制中 → 停止 → 右下角结果卡 → 打开/保存/关闭
```

异常路径：

- 屏幕捕获权限失败：提示用户开启屏幕录制权限。
- 编码失败：保留选区，提示重试。
- 文件过大：提示降低尺寸/帧率/时长。

## 5. 技术方案

- 捕获：主进程 `desktopCapturer` 获取屏幕源；覆盖层 renderer 通过 `getUserMedia` 建立视频流。
- 裁切：Canvas `drawImage(video, sx, sy, sw, sh, ...)`，按 `scaleFactor` 把选区 DIP 映射到视频物理像素。
- 抽帧：固定 15 FPS `setInterval`；原始尺寸长边上限 1920。
- 编码：Web Worker + `gifenc` 1.0.3（MIT）。
  - `quantize()` 生成调色板，`applyPalette()` 生成索引帧。
  - 量化格式使用 `rgb565`，比 `rgb444` 保留更多颜色信息。
  - `GIFEncoder.writeFrame()` 逐帧写入，避免保存全部原始帧。
  - 帧数据用 `ArrayBuffer` transfer 给 Worker；Worker 忙时丢帧，避免内存膨胀。
  - `finish()` 只写结束标记，必须再调用 `bytes()` 取结果。
- 待机控制条：直接渲染在覆盖层内，跟随 Demo 的胶囊样式；开始按钮显示红色圆点和“开始”文字。
- 录制控制条：独立 `BrowserWindow`，内容保护，始终置顶，按选区 X 轴横向居中，不进入捕获。
- 录制边框：覆盖层内绘制，使用 `outline` 画在选区外侧；裁剪区域从选区边界开始，红框不进入成片。
- 结果卡：独立的小窗口固定在屏幕右下角，通过 `snapglass-media://` 读取临时文件。
- 保存：主进程保存对话框 + 复制临时文件。
- 帧间隔：GIF 的 `delay` 使用两帧真实采集时间差，而不是固定 `1000 / fps`；大选区量化慢或丢帧时，播放总时长仍与录制时长一致。
- 编码性能：GIF 长边上限 720；大帧用降采样样本生成调色板，再映射完整帧；编码完成后立即调度下一帧，目标 15 FPS。

### 许可

不引入 GPL/AGPL FFmpeg。使用 MIT 许可的 `gifenc`，随应用打包。

## 6. 验收标准

- 选区可进入 GIF 待机控制条，开始按钮显示红色圆点和“开始”文字。
- 倒计时结束后开始录制，计时准确，60 秒自动停止。
- 录制控制条按选区横向居中，不出现在 GIF 画面中。
- 15 FPS 可正常编码，GIF 可播放。
- 保存生成的 GIF 可被系统看图器打开。
- 结果卡保持显示，直到用户关闭。
- 单测覆盖 encoder/worker 输入输出、尺寸计算、时长限制。

## 7. 已知限制

- 高 DPI、多显示器需要按 `scaleFactor` 映射，P2 先在 100%/150% 验证。
- 高帧率 + 原始尺寸 + 60 秒会产生较大 GIF；GIF 输出长边限制为 720，小选区不受影响。
- 录制期间覆盖层可见但鼠标穿透；全屏选区时控制条可能没有完全位于选区外的空间。
- 大选区下 GIF 量化可能低于 15 FPS；此时会丢帧，但每帧显示时长按真实时间补偿，不会加速播放。
- 为避免全屏 GIF 只有约 1.5 FPS，GIF 长边上限为 720；需要更高清晰度时请缩小选区。
- 720×405 全屏 GIF 实测约 14.7 FPS；更大分辨率会明显降低帧率。
