# P16 文字标注增强：自适应输入框、拖动、会员字体

## 背景

截图覆盖层与钉图编辑共用 `AnnotationCanvas` 的文字工具。原实现有三个问题：

1. 输入用单行 `<input>`，宽度固定，文字多了只显示前半段，后半段不可见。
2. 已输入的文字虽可拖动，但 hover 光标是 `move`，没有「十字可拖动」的明确反馈。
3. 只能使用系统默认字体，无法体现会员权益。

## 目标

- 输入框宽度随内容自适应；内容只能落在截图选区矩形内；靠近选区边框自动换行；换行后仍快触边时禁止继续输入并 toast「超出截图区域~」。
- 文字工具下，hover 到已输入文字框边框时光标变十字，可整体拖动，文字跟随。
- 新增多种打包字体；免费用户只能用默认字体，会员可用全部。

## 设计决策（已确认）

| 项 | 决策 |
|---|---|
| 截图区域 | 截图选区矩形（`selection`） |
| 断行 | 中文按字、英文按词；超长词按字符强制断开；显式换行保留 |
| Enter | Enter 换行，Ctrl+Enter 提交；blur 提交，Esc 取消 |
| 十字光标 | 仅文字框边框（容差 6px）；框内仍是文字光标，点击进入编辑 |
| 会员字体点击 | 免费用户点击会员字体直接打开购买窗 |
| 字体来源 | 打包 woff2（free-font 仓库，开源可商用）；思源黑体替换方正黑体；沐瑶随心手写体替换日文的「手写杂字体」 |

## 风险与未验证

- `field-sizing: content` 依赖 Chromium 支持（Electron 40 / Chromium 140），需真机验证；不支持时改用 JS 测量显式宽高。
- 字体授权：free-font 仓库声明免费可商用；方正黑体已替换为思源黑体以规避争议。
- 体积：安装包增加约 34MB，需用户知晓。
- 免费额度/授权服务不改动，会员判定复用 `license:status`。
