# P1 OCR + 翻译 · 需求与验收

> 项目：Pixmint  
> 版本：0.2.0  
> 分支：`feat/p1-ocr-translation`  
> 日期：2026-10-19  
> 状态：Windows OCR + 结果窗口 + 翻译配置已实现；PaddleOCR/macOS/ECDICT 数据待接入

## 1. 目标

截图后直接识别选区内文字，并按结果类型进入两条路径：

- 单词/短语：音标、释义、发音、复制
- 句子：原文可编辑、翻译、原文/译文分别复制

## 2. OCR 后端策略

PRD 目标后端仍是 PaddleOCR（onnxruntime-node + PP-OCRv4）。当前网络被代理拦截，无法下载模型和新增依赖，因此 P1.0 采用可插拔结构：

| 优先级 | 后端 | 状态 |
|---|---|---|
| 1 | Windows.Media.Ocr（系统 OCR） | 已在本机验证中文识别 |
| 2 | PaddleOCR ONNX | 接口预留，待模型可下载后接入 |
| 3 | macOS Vision | 接口预留，待 Mac 实机接入 |

Windows OCR 输出会在中文字符间插入空格，主进程统一清洗后再进入分词/翻译。

小选区 OCR：Windows OCR 对 30–40px 高的菜单文字经常返回空。识别前按选区高度自动放大（<80px 4×，<160px 2×，上限 8192px / 1600 万像素），已在 135×35 的托盘菜单文字上验证。

## 3. 功能范围

### 3.1 截图入口

- 标注工具条“识别”按钮：识别原始选区，不包含标注笔迹；OCR 弹框只显示原文和“复制”。
- 标注工具条“翻译”按钮：识别后打开独立翻译弹框。
- 新截图开始前关闭旧 OCR/翻译弹框，同一时间只保留一个。
- OCR 结果窗口独立显示，不阻塞截图/贴图。

### 3.2 智能分流

- 英文 1–3 个词、或中文 1–8 个字且无句末标点 → 单词卡片。
- 其他 → 句子面板。
- 用户可修改 OCR 原文，修改后重新判断类型并重新翻译。

### 3.3 单词卡片

- 单词/短语
- 音标（词典数据存在时）
- 词性 + 中文释义
- 发音按钮（Web Speech API）
- 复制单词/释义
- 词典缺失时明确提示，不伪造释义

### 3.4 句子面板

- 原文 textarea，可编辑
- “重新识别类型”与“翻译”
- 译文展示
- 原文/译文分别复制
- 未配置翻译服务时引导去设置页，不 Mock 译文

> 0.2.12 起：翻译弹框打开后自动翻译，原文改为只读；原文和译文都可鼠标选中复制，底部不再显示语言切换/翻译/复制按钮。

> 0.2.13 起：OCR 弹框点击“复制”后写入剪贴板并自动关闭弹框。

### 3.5 翻译服务

- OpenAI 兼容接口：base URL、model、API Key
- DeepL：API Key，默认 free endpoint
- 目标语言：`zh-CN` / `en-US`
- API Key 使用 Electron `safeStorage` 加密，落在 `userData/secrets.json`
- 渲染进程永远拿不到明文 Key

### 3.6 发音

- 使用 `window.speechSynthesis`
- 英文单词使用 `en-US`，中文使用 `zh-CN`
- 系统无对应语音时静默失败并提示

## 4. 词典数据

- 目标数据源：ECDICT SQLite（离线）
- 当前机器未找到 ECDICT 数据，P1.0 内置一组常用词条用于闭环演示
- 未命中词条时显示“暂无词典数据”，不伪造释义
- 预留 `DictionaryProvider` 接口，后续接入 ECDICT SQLite
- 本地翻译模型锁定 OPUS-MT（en↔zh 量化 ONNX）；当前网络无法下载依赖/模型，尚未内置

## 5. 非目标

- 整页/全屏翻译
- PDF/图片批量 OCR
- 云端历史同步
- 自动下载 PaddleOCR 模型

## 6. 验收标准

- Windows 中文/英文截图可识别，中文空格被清洗
- 单词与句子分流正确
- 单词卡片可发音、复制
- 句子可编辑并调用已配置翻译服务
- 未配置 Key 时不显示假译文
- Key 不出主进程，重启后仍可用
- 单元测试覆盖文本清洗、分流、翻译请求构造
- 设置页、OCR 窗口、覆盖层构建通过

## 7. 已知限制

- 当前网络无法下载 PaddleOCR 模型，P1.0 先使用 Windows 系统 OCR
- macOS 端 OCR 后端尚未实机接入
- ECDICT 数据未随包分发，P1.0 词典覆盖有限
- 翻译服务需要用户自备 Key 和可用网络
- 真实联网翻译未在开发机验证（网络被代理拦截）
