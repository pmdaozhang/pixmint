# Pixmint v0.5.2（Windows）

这是长截图滚动兼容性修复补丁。

## 修复

- 当目标应用一次滚轮滚过选区大部分高度时，0.5.1 仍可能报“滚动幅度过大”。0.5.2 增加 Windows UI Automation `ScrollPattern` 小步滚动：回滚到起点后按约 47px 的小步前进，避免一次滚半页。
- 保留 0.5.1 的滚动条边缘裁剪、1px 接缝修复、HUD、预览、保存/复制和取消清理。

## 验证

- 13.8 倍滚轮测试页（模拟一次滚约 690px）：700×3396，完整拼接。
- 带移动滚动条的测试页：700×3396。
- 普通长截图 smoke：700×3396。
- 长截图专用 E2E：入口、HUD、暂停/继续/完成/取消、预览、复制、保存、不可滚动窗口通过。
- `pnpm typecheck`、`pnpm test`、`pnpm build` 通过。

## 已知限制

- 如果目标应用既不支持 UI Automation 滚动，又只能整页滚动，仍无法保证重叠；此时会提示框选更高区域或关闭单页滚动。
- VS Code、UAC/受保护窗口、网络懒加载图片未验证。
- 125% / 150% / 200% DPI 和多显示器按用户要求不测。
- 安装包未代码签名，首次安装可能触发 SmartScreen。

## 升级

- 0.5.1 可在应用内检查更新到 0.5.2，预期命中差分下载。
- 0.4.1 也可直接更新到 0.5.2。
- 0.3.10 老用户需先手动安装一次 0.4.0。
