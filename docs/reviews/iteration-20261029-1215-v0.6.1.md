## 本轮变更

- 功能：长截图下线，删除工具栏入口、引导页、窗口长截图流程、HUD/预览/边框/实时选区窗口。
- 影响模块：主进程启动与 IPC、preload/API 类型、覆盖层工具栏、渲染路由、引导页、回归映射和发布检查清单。
- 公共接口变更：删除 `longCapture`、`windowTarget`、`windowLong` API 和长截图专用类型；`OverlayAction` 不再包含 `long`。
- 数据格式变更：无。
