## 本轮发现并修复

| 问题 | 影响 | 修复 |
|---|---|---|
| 窗口目标 sidecar 未遵循 `id,command` / `id|payload` 协议 | 首次选择窗口直接 `error:command` | 统一请求解析和响应 ID |
| `GetCurrentThreadId` 声明在 `user32.dll` | 无法读取窗口内容区 | 改为 `kernel32.dll` |
| 选区向左/向右拖动时整体平移 | 对边不固定，越界后选区被挪走 | 按被拖边分别限幅，固定对边 |
| 滚动目标可能受 z-order 影响 | 可能滚到别的窗口 | 校验滚动 hwnd 与用户选择窗口一致 |
