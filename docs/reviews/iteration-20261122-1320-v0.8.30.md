## 本轮变更

- `src/renderer/src/purchase/PurchaseApp.tsx`：分享抵扣报价移出首帧门控，本地数据就绪即发 `contentReady`，报价返回后再更新价格。
- `src/main/windows/purchase-window.ts`：增加购买窗 `did-finish-load`、`ready-to-show`、`show timing` 诊断日志。
- `build/installer.nsh` + `electron-builder.yml`：安装时把 `$CMDLINE` 写入 `%APPDATA%\snapglass\install-ref.txt`。
- `src/main/index.ts` + `src/main/referral-service.ts`：首启读取安装命令行，解析 `--ref` 并调用 `/referral/friend`；成功或排队后清理文件。
- 官网：下载按钮统一走 `/download`，nginx 把 `?ref=` 写进安装包文件名；`release.json` 兼容 `installer` 字段。
- 版本号切到 0.8.30，CHANGELOG 更新。

## 债务台账

- 安装 ref 遇到 4xx 无效码时会保留文件、每次启动重试；正常分享码不会触发，后续可加尝试次数。
- nginx 的默认安装包文件名写死了 0.8.30，后续发版需同步更新 map。
- `docs/reviews/metrics.json` 仍停在 0.8.28，基线版本 0.4.1；不影响本次门禁，但建议下次发版前重新采集。

## 下轮建议

2. 发版流程把 nginx map 的版本号纳入检查单。
3. 重新采集 metrics 与基线，消除 WARN。
