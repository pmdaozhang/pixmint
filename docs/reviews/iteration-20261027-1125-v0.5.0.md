## 本轮变更

- 新增覆盖层“长截图”入口、HUD、独立预览窗口和工具栏图标。
- 新增 Windows 滚动 helper、重叠匹配、固定表头、增量拼接、上限和临时文件清理。
- 修复每个拼接缝多出 1px 深色横线：所有采集帧统一裁掉最后 1 个物理像素行，保证首帧/后续帧尺寸一致。
- 代价：最终长图比选区少 1px，肉眼不可见。
