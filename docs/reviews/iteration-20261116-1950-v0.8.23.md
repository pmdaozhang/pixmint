## 本轮变更

- 工具栏图标按实际路径包围盒统一光学尺寸，外框统一 15px；图钉单独放大，箭头、文字、关闭单独缩小。
- 选中态改为深色块 + 底部强调条；浅色 `rgb(43, 43, 43)`、深色 `#3a3a3a`，解决深色工具栏下选中块与背景同色的问题。
- B/I/U 共用字形盒子，统一字号、基线和垂直居中；斜体改用衬线斜体 I。
- GIF 图标 18px、字号 9 并保留内边距；视频图标 17px，红色录制点上下居中。
- 浅色/深色 toast 统一为幽灵胶囊，覆盖 overlay、设置、反馈、钉图、会员页、购买窗内联消息和 OCR/翻译原生提示。
- 托盘图标改为读取 Windows `SystemUsesLightTheme`，跟随任务栏主题而非应用主题；增加缓存和销毁保护。
- 版本号提升到 0.8.23，生成安装包、`latest.yml`、`.blockmap` 和 `.sha256`。
