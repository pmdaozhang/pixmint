## 本轮变更

- 版本从 0.6.2 提升到 0.7.0。
- 短选区钉图不再分别套 80×60 最小值，宽高使用同一缩放比例。
- `<img>` 从 `object-fit: fill` 改为 `contain`。
- PaddleOCR 与 Windows OCR 返回原图坐标的文字行框。
- 新增 `pin:recognize-text` IPC 和钉图透明文字层。
- 支持鼠标拖选、双击选词、`Ctrl+A`、`Ctrl+C`。
- 文字区域不触发窗口拖动；空白区域拖动、滚轮缩放和双击穿透保持原行为。
- 编辑图片后重新 OCR；OCR 失败降级为普通钉图。
- OCR 像素转换改为原地处理，减少每次识别的整图分配。
- 生成并上传 `Pixmint-Setup-0.7.0.exe`、`latest.yml`、`.blockmap` 和 `release.json`。
- 官网 `release.json` 已切换到 0.7.0，下载按钮和版本号通过线上页面验证。
- 新增 `e2e:pin-text`，覆盖文字选择、缩放对齐、编辑重识别、失败降级和 30 次连续钉图。
