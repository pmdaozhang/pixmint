## 本轮变更

- 功能：Windows 应用内检查更新、下载、SHA-512 校验、静默安装、自动重启。
- 影响模块：主进程更新器、preload API、共享类型与状态机、设置页更新卡片、打包与发布配置。
- 公共接口变更：新增 `window.snapglass.updater` IPC；无破坏性变更。
- 数据格式变更：无；设置 schema 不变。
