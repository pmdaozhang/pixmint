## 本轮变更

- 输入框由单行 `<input>` 改为多行 `<textarea>`，`field-sizing: content` 随内容自适应，`max-width/max-height` 限制为选区剩余范围。
- 新增 `src/shared/text-layout.ts`：中文按字、英文按词断行，超长词按字符断开，显式换行保留，返回行宽/行高/溢出。
- 超限时拒绝本次输入并触发 `onTextOverflow`，覆盖层/钉图弹 toast「超出截图区域~」。
- Enter 改为换行，Ctrl+Enter 提交；blur 提交、Esc 取消。
- 画布文字按 `\n` 多行绘制，`annotationBounds` 高度按行数计算，命中与十字光标边框判定一致。
- 文字工具 hover 文字框边框（容差 6px）显示 `crosshair`，框内仍为文字光标；拖动整框并同步文字。
- 新增 10 种打包字体（woff2，共 35.88MB），覆盖层与钉图共用字体选择器；免费用户仅默认字体，点击会员字体打开购买窗。
- 会员判定复用 `window.snapglass.license.status()`，不改动授权服务。

## 不可逆决策

| 决策 | 是否可回滚 | 回滚方式 |
|---|---|---|
| 打包 10 种字体（35.88MB） | 是 | 删除 `assets/fonts` 与 `fonts.css`、`FONT_CHOICES` |
| Enter 改为换行 / Ctrl+Enter 提交 | 是 | 恢复 `onKeyDown` 的 Enter 提交分支 |
| 断行/权限抽成纯函数 | 是 | 内联回组件，保留测试 |
| 方正黑体替换为思源黑体、手写杂字体替换为沐瑶随心手写体 | 是 | 换回原字体文件并改 `FONT_CHOICES` |

## 债务台账

- 新增：安装包体积较 0.8.23 增加约 34MB，需在发版前确认分发与下载体验。
- 新增：高 DPI 下多行输入框、字体渲染与十字光标复核。
- 新增：macOS 文字工具与字体选择器实机验证。
- 已偿还：单行输入框裁字、文字框拖动光标不明确、无字体选择。

## 下轮建议

1. 发版 0.8.24 时重新采集 metrics、生成对应版本回顾并跑 `release-gate.mjs`。
2. 在 125% / 150% / 200% DPI 下复核多行输入框与字体。
3. 关注安装包体积对下载转化率的影响，必要时改为按需下载字体。
