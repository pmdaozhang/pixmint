# 迭代回顾 2026-10-30 / v0.6.1

## 结论

`blocked`

客户端反馈功能已完成并通过真实 Electron E2E，但生产后台只实现文本接口，截图附件接口尚未上线。
用户粘贴截图后文字可以提交，截图会被明确提示“未上传”，因此核心截图反馈路径尚不能发布。

## 本轮变更

- 功能：托盘“意见反馈…”，独立反馈窗口，文字 + `Ctrl/Cmd+V` 截图，最多 10 张，5MB 自动压缩。
- 功能：文本 JSON 提交、附件逐张 multipart、离线队列、2s → 8s → 30s 重试、`request_id` 幂等。
- 影响模块：主进程启动/托盘/IPC、preload/API、渲染路由、反馈窗口、共享契约、测试与文档。
- 公共接口变更：新增 `feedback.submit`、`feedback.onStatus`；新增 `FeedbackSubmitInput` / `FeedbackSubmitResult` / `FeedbackStatusEvent`。
- 数据格式变更：新增 `<userData>/feedback-queue.json`，只保存文字和环境信息，不保存截图。
